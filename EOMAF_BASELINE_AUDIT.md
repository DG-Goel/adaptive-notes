# NOETRA / Adaptive Notes — E-OMAF baseline audit

**Audit date:** 2026-11-15 (Asia/Calcutta)  
**Scope:** Local source, configuration declarations and saved test evidence in `C:/Projects/adaptive-notes`.

## Method and evidence rules

This was a static audit. No tests were rerun, no services were started, and no provider requests were made. The report is the sole workspace deliverable. Source paths below are relative to the workspace root. Implementation status describes executable code found in the snapshot. **Historical verified** means saved runner output explicitly records the stated result for that execution. **Reported** means a project document describes a result. **UNVERIFIED** means evidence is insufficient for the corresponding behavior in this snapshot. A recorded test failure applies to its specific historical execution. Saved runs lack commit attestation, so every dimension remains UNVERIFIED for the current snapshot as a whole.

## Snapshot and environment

- Git HEAD and working-tree status are unavailable. `git rev-parse HEAD` returned “not a git repository” at the workspace root, `backend/`, and `NOETRA/`. Commit, branch, cleanliness and linkage between saved results and reviewed source could not be established.
- Backend dependency declarations are in `backend/requirements.txt`, `backend/requirements-transcription.txt` and `backend/requirements-transcription-lock.txt`. Local `backend/.venv/` and `backend/.venv-transcription/` directories exist. The video job runner references the latter's Windows interpreter explicitly. Installed package versions, CUDA availability, cached model integrity and service readiness were unverified.
- `backend/.env.template` declares provider configuration and five organization slots. Tutor configuration comes from `backend/Universal-AI-Tutor/src/config.py`, `backend/Universal-AI-Tutor/.env.example`, `backend/Universal-AI-Tutor/pyproject.toml` and `backend/Universal-AI-Tutor/docker-compose.yml`. Runtime dotenv values, credentials, organization identifiers and local media content are omitted. Configured defaults below are source declarations.
- ASR defaults to Faster-Whisper `small.en`, CUDA `int8_float16`, English, word timestamps and local-only model loading. CUDA initialization fallback uses CPU `int8`. The video job selects a local model directory from its model cache, so its effective model revision is unknown. PDF OCR initializes RapidOCR with ONNX Runtime. OCR weight identifiers were not established.
- The organization scheduler constrains the extraction model to Groq `openai/gpt-oss-120b`. The provider library also declares `gemini-2.0-flash-exp` as a Gemini constructor default. Tutor defaults declare Groq `llama-3.3-70b-versatile`, embeddings `BAAI/bge-small-en-v1.5` and reranker `cross-encoder/ms-marco-MiniLM-L-6-v2`. Effective provider, model revision and quota at runtime are UNVERIFIED.
- The video notes HTTP service binds loopback port 8765 and relays tutor calls to loopback port 8000. `NOETRA/src/config/endpoints.ts` defaults to the latter's `/api/v1` prefix and enables frontend mock mode only when `VITE_USE_MOCK_API` equals `true`. The tutor has a separate mock LLM implementation. Neither flag establishes how historical runs were configured.

## Recommended controlled experiments

Use synthetic or consented fixtures and isolated state. Capture a source revision or file-hash manifest, dependency versions, effective model settings without credentials, fixture hashes, test node IDs and complete outcomes.

1. **Transcription and OCR recovery (O1, O3, O4).** Pair a fixed speech alignment reference with known page/frame text. Inject CUDA initialization, iterator, page processing and persistence failures. Measure word and character error, timestamp deviation, missed text, artifact retention and duplicate completions after interruption.
2. **Parallel scheduler and authorization (O2, O3, G1, G2).** Use a stub provider and a temporary SQLite store. Race workers on the same request, inject a timeout after acceptance, exhaust quota, mutate a bound request and interrupt between reservation and dispatch. Measure provider invocations per request, admission decisions, unresolved reservations and audit record completeness.
3. **Round 1 and Round 2 provenance (O1, O4, G3, G4).** Replay fixed model responses with correct, ambiguous and fabricated claims, altered evidence and malformed visuals. Compare extracted and refined output against reviewer-labelled claims. Measure verified evidence coverage, unsupported claims, rejection behavior and base-note preservation. Require artifacts for reviewer approval, rejection and correction.
4. **Tutor and local services (O1, O2, G2).** Use two deliberately similar lecture fixtures, fixed query answers and a stub generator. Include out-of-scope questions, the historical parent-expansion case, a stale index marker, an unavailable tutor and a video worker restart. Measure retrieval recall, citation correctness, abstention, source isolation, observable error state and job recovery.

These experiments describe future evidence collection. None was executed during this audit.
