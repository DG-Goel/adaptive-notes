# Study notes

## classification

## Classification Types

- **Binary Classification**: The model outputs one of **two** possible categories.
- **Multi‑class Classification**: The model selects from **more than two** distinct categories.

## Regression Problems

- These involve predicting a **continuous numeric value**. Unlike classification, the output is not limited to a fixed set of categories; it can be any real number.

### regression

## Problem Overview

- **Scenario**: The task involves generating an output that can be **any numeric value**. 
- **Example**: The model might infer a value such as a **house price** based on the given context.

*The goal is to design a system that can produce a plausible numeric result for a wide range of possible inputs.*

## supervised learning

### x and y pair

## Supervised Learning: Input and Output Variables

- **Input variable** (`x`): The feature or set of features provided to the model.
- **Output variable** (`y`): The target or label the model aims to predict.

In supervised learning, the model learns a mapping from `x` to `y` using labeled training data.
