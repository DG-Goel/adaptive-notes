# Two stages using Groq openai/gpt-oss-120b

A reads the complete unchanged chunk and emits one concise scoped teaching proposition per row with canonical provenance and one contiguous excerpt. A keeps example observations, naming corrections, alternatives and compiler events distinguishable. For the mismatch and its repair, use separate rows tied by an explicitly supported event relation. For a proposition requiring multiple excerpts, split the proposition or omit it if the resulting rows cannot independently be understood. A avoids categories, aliases, procedures and pointer maps. It must still preserve scope, distinguish spoken examples from code and omit inference.

Validate A before opening B. Check shape, finish status, exact text against the supplied source unit, and source ID membership. Assign local immutable fact IDs after validation. An ambiguous repeated quote can retain the exact quote with no selected offset, consistent with the existing evidence policy. Preserve source hash and chunk identity on the run record. Neither an ID nor a quote certifies the claim's meaning.

B receives only the validated A facts and evidence, with their IDs, and the eight category contracts. It selects related facts conservatively and returns typed items with per-field fact references. A field may reference multiple facts for a conjunction or a related error and repair. The same fact may support multiple fields where its meaning permits. B carries no original transcript beyond the A excerpts. A local resolver derives canonical source IDs and expands fact references into the current exact quote and JSON Pointer representation. Run existing strict schema and evidence checks on that expanded representation. Reject references outside this A snapshot. Keep original source for local checks, outside B's prompt.

B cannot recover a fact omitted by A. It also cannot be trusted to preserve claim scope merely because a reference exists. A manual review must check A against source, B against A, and expanded output against source. A compact B reference format removes repeated quote text from model output. A full current-schema B response would preserve much of the original output burden. Both are design variants for offline size comparison only.
