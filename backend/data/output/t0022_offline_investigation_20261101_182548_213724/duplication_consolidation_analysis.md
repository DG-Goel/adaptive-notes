Consolidate semantic duplicates, not shared words. Preserve every distinct fact, numeric value, condition, alternative and scope once. Definitions and examples can coexist when they contribute distinct teaching content. Do not use an item-count quota to justify deletion or merge unrelated errors.

Each object still needs content, subtype fields, canonical source references and evidence. Every populated scalar, array element and dictionary key retains an independent RFC 6901 path. One exact excerpt may support several paths only when it actually supports every associated claim; other passages need additional evidence. Parent collections cannot satisfy children. No schema indirection, automatic deletion or post-hoc ID rewriting is proposed.
